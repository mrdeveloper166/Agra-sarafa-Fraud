# Agra Sarafa Fraud

A web-based project created to present and organize information related to the Agra Sarafa fraud case in a structured and user-friendly format.

## 🚀 Features

* Clean and responsive website
* Case-related information pages
* Structured content presentation
* Image and media support
* Mobile-friendly design
* Easy-to-navigate interface

## 🛠️ Technologies Used

* PHP
* HTML5
* CSS3
* JavaScript
* Bootstrap
* MySQL

## 📌 Project Purpose

This project demonstrates web development skills while providing a structured platform for presenting publicly available information and documentation related to the case.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/mrdeveloper166/Agra-sarafa-Fraud.git
```

Move the project to your XAMPP `htdocs` directory.

Start **Apache** and **MySQL** from XAMPP.

If a database is included, import the provided SQL file into phpMyAdmin and update the database configuration.

Open the project:

```text
http://localhost/Agra-sarafa-Fraud/
```
